# :material-clipboard-list: Summary

The Summary page shows the open project as an indented list: its name
and description, the sample model with its structure and components, and
the analysis. These are the settings a save writes to the project's
record. The page reads the project again each time you open it, so it
shows your latest changes.

**Continue** on the Analysis page opens this page.

You can select the text and copy it. If the project can't be listed, the
reason shows in red instead.

The **Export summary** group in the sidebar is off in this version.
