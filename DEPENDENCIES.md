# Third-party open-source software

EasyShapes uses the open-source software below. If you find a licensing
problem, please open an
[issue](https://github.com/easyscience/shapes-app/issues).

## Libraries

- [shapespyer](https://gitlab.com/simnavi/shapespyer): BSD-3-Clause.
  Its own dependencies are listed in its `pyproject.toml`.
- [EasyApp](https://github.com/easyscience/EasyApp): BSD-3-Clause.
- [Qt for Python (PySide6)](https://doc.qt.io/qtforpython-6/): LGPL-3.0.
  The Qt Quick 3D and Qt Graphs modules, which draw the structure viewers
  and the scattering chart, are GPL-3.0.
- [NumPy](https://numpy.org): BSD-3-Clause.

## Fonts

These come with EasyApp. All use the
[SIL Open Font License 1.1](https://openfontlicense.org).

- [PT Sans](https://fonts.google.com/specimen/PT+Sans) and
  [PT Mono](https://fonts.google.com/specimen/PT+Mono)
- [Encode Sans](https://fonts.google.com/specimen/Encode+Sans), Encode
  Sans Condensed and Encode Sans Expanded
- [Nunito](https://fonts.google.com/specimen/Nunito)
- [Font Awesome 5 Free](https://fontawesome.com) (Solid)
